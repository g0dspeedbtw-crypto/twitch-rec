## v5.0.2 — Глубокий фикс вылетов Студии, QThread и автообновлений
### Исправлено
- **Устранён главный источник вылетов (`QThread: Destroyed while thread is still running`)** — во всех 20+ фоновых воркерах (`loadStudioTimelineAssets`, `renderNleProject`, `runDmcaClean`, Автопилот, Автопостинг, AI, OBS) очистка потока теперь выполняется строго через единый `_track_worker()` только после сигнала `finished`, когда C++ поток Qt гарантированно завершён. Студия больше не вылетает при открытии видео!
- **Исправлены кривые обновления (`updater.py`)**:
  - Уведомление о новой версии больше не появляется, пока билд **именно для вашей ОС** (macOS `.zip`/`.dmg` или Windows `.zip`/`.exe`) реально не загружен в GitHub Releases;
  - На macOS замена `.app` теперь выполняется надёжно через `ditto` + снятие карантина `xattr -cr` + ad-hoc `codesign`, чтобы macOS не блокировал обновлённое приложение;
  - На Windows добавлена пауза 0.9с и до 4 попыток копирования файлов, чтобы заблокированные DLL обновлялись чисто.
- **Ускорена и стабилизирована работа Студии** — генерация раскадровки и аудио-волны ускорена в 4 раза, а перемотка видео (`seekStudioMonitor`) получила дебаунс 110 мс, чтобы быстрые клики по таймлайну не плодили лишние FFmpeg-процессы.

  4. **▶️ Авто-загрузка на YouTube** с прикреплением обложки, выбором доступа (`По ссылке / Unlisted`, `Приватный`, `Открытый`) и отправкой ссылки в Telegram;
  5. *(Опционально)* дополнительная нарезка вирусных Shorts 9:16 с каждой части.

  - `shazam_smart` — точечный сканер треков через `shazamio`, заглушающий только обнаруженные коммерческие треки;
  - `off` — оригинальный звук без обработки.
- **Умная авто-разбивка для автопилота** — при включении потокового автопилота у канала с отключённой разбивкой программа автоматически выставляет разбивку по `60 мин` (1 час).
